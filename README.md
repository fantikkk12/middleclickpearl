# Middle Click Pearl — Fabric 1.21.4

Порт мода из TopkaHitBoxes-1_16_5.jar (Forge 1.16.5).
Средняя кнопка мыши бросает эндер-жемчуг (хотбар или инвентарь).

## Сборка
Нужны JDK 21 и Gradle (или gradle wrapper):

    gradle build

Готовый jar: build/libs/middleclickpearl-1.0.0.jar
Требуется Fabric Loader 0.16+ и Fabric API для 1.21.4.
